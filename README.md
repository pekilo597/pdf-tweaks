# PDF Studio

App local para unir, ordenar, rotar, eliminar y extraer páginas de archivos PDF. Todo se procesa en el navegador.

## Iniciar en Windows

1. Instala [Node.js LTS](https://nodejs.org/).
2. Abre PowerShell en esta carpeta.
3. Instala las dependencias y arranca Vite:

```powershell
npm install
npm run dev
```

4. Abre la dirección local que muestra Vite (normalmente `http://localhost:5173`).

Para crear la versión de producción, ejecuta `npm run build`.
